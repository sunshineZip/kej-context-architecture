## Document Purpose

Preserves relevant excerpts from an externally found ancestor chart, found by the human via a personal Google search (not part of KEJ's own material) and shared for cross-checking against the Hopp-slægten research already in hand. Working project-layer note — not yet promoted into a domain, since no Hopp-slægt domain exists yet (Phase 3). Same pattern as `external-source-hopp-herredsfoged.md`, which this file is modeled on directly.

**Unlike that earlier source, this is not reproduced in full.** The earlier akj-cbj.dk page was a personal genealogy blog post with no stated copyright restriction; this document is a formally published, copyrighted work whose own cover page states "For værker, som er omfattet af ophavsret, må PDF-filen kun benyttes til personligt brug" (copyrighted works in this library may only be used for personal purposes). Only the specific passages relevant to this family's own research are excerpted below, with page numbers, consistent with normal scholarly citation practice — not the full 36-page document. The PDF file itself has not been added to this repository for the same reason; see the Open Items section for the storage recommendation.

> **Note:** This is an ancestor chart for a third party — Dr. Jonathan Høegh Leunbach (1884-1955), a Danish physician and sexual-health/abortion-rights reformer — not a document about this family directly. The relevance is that Leunbach's own ancestry passes through the same root ancestor as this family's Hopp-slægten research: Knud Danielsen Hopp (b. ~1640, d. 1723). Leunbach descends from a different child (Niels Jørgen Knudsen Hopp, the "01C" chapter's subject) than this family's own direct line (through Daniel Knudsen Hopp, "01-a").

## Cross-Reference Against This Family's Own Material

### 1. Confirms and likely recovers "lost" chapter 01 content — but is not independent

The chart's entry #196 (p. 23-25) for Knud Danielsen Hopp matches `family-tree/tree.ged#I364` exactly: b. ~1640, d. 1723, m. Berte/Birthe Pedersdatter, herredsfoged i Salling Nørre Herred from 1673, herredsskriver from 1688. It includes a detailed, well-sourced biography — his time as fuldmægtig for Jørgen Marsvin, presiding as herredsfoged over the 1686 "Tise Trolde" witch trial, his residence at "Bundgaard" in Sdr. Thise, the 1687-88 sale of fishing rights in Nibe Fjord.

**This is very likely KEJ's own research, not a second independent source.** The chart's own source list for this entry (p. 25) names, alongside published works ("Skiveegnens Jul 1978," "Fra Himmerland og Kjær Herreder 1935-1937," two Jeppe Aakjær books), **"Knud Erik Jakobsen, Risum"** directly — the same pattern already found for the akj-cbj.dk source (`external-source-hopp-herredsfoged.md`, which also cites "Skiveegnens Jul 1978" as its primary source). Given `family-tree/tree.ged`'s own chapter "01" arrived with almost no content — only the overview table survived, no individual biography (`grandfather-review/queue.md` item 18) — this chart's detailed account may be recovering exactly what was lost from KEJ's own original article, republished here by a different compiler. Worth confirming directly with KEJ rather than treating it as independently corroborating.

### 2. Two previously-unconfirmed children, named for the first time

`family-tree/tree.ged#I364`'s own note states only 4 of Knud Danielsen Hopp's children were confirmed to exist from the material in hand (Daniel = "a.", Peder = "b.", Niels Jørgen = "c.", Knud = "f."), with children "d." and "e." explicitly unconfirmed. This chart (p. 25-26) names all six, in birth order, matching that lettering exactly:

### 3. The "further back than 1640" hypothesis — still unresolved, same problem as before

The chart (p. 23) repeats the same speculative earlier-generations claim already tracked in `grandfather-review/queue.md` item 2 (Hans Hop 1562-1624 → Mads Hopp 1590-1650 → Daniel Madsen Hopp → Knud Danielsen Hopp), but cites a *different* source for it: a privately-copied 1989 book, "Slægten Hop," held at Landsarkivet i Viborg (shelf mark Q/H-69) — not the akj-cbj.dk website already on file. The chart's own author flags the identical chronological problem already noted in item 2: the book gives Daniel Madsen Hopp's birth as 1633, which cannot be reconciled with fathering a son born in 1640, and states plainly that the book cites no sources of its own, so "indtil videre må de opfattes som en hypotese" (for now must be treated as a hypothesis). Two independent compilers repeating the same unverified claim from two different secondary sources is worth noting, but doesn't change the underlying evidence — no reliable path past 1640 yet.

### 4. One generation further than currently modeled on the Hjardemaal side

`family-tree/tree.ged` already carries Niels Jørgen Knudsen Hopp's daughter Dorthe Nielsdatter Hopp (`I388`, via the "01C" chapter's "our line" depth) through the Hjardemaal family down to Søren Nielsen Hjardemaal (`I644`, b. 1787 per `tree.ged` / 1786 per this chart — a small discrepancy worth noting), and explicitly stops there per the "our line" depth policy (`I644`'s own note: "6 børn ... ikke modelleret enkeltvis her"). This chart (p. 9-10) extends one generation further, through one of those unmodeled children: Christen Mathias Hjardemaal (b. 1812, a merchant and plantation owner on St. Thomas, Danish West Indies) → Cassandra Vilhelmine Hjardemaal (b. 1845) → Jonathan Høegh Leunbach himself (b. 1884).

The same source-independence caveat applies here too: the chart's own Forord (p. 3) names its source for "the older Hjardemaal ancestors" as Jens Aaberg's 2008 book on jordemoder Anne Cathrine Nicolajsdatter Hjardemaal — plausibly the same underlying source already reflected in `tree.ged`'s own "01C" chapter content (which independently already covers a *sibling* line of this same Hjardemaal family in comparable depth — the Nicolai Severin Nielsen Hjardemaal / Vestindien / Simmons-family-in-Sweden line at `tree.ged` lines 7005-7015).
