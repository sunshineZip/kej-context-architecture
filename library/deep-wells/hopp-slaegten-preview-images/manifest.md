## Document Purpose

Two images found embedded in a *different* manuscript ("Boe-slægten fra Mors og Fur," `library/deep-wells/boe-slaegten-fra-mors-og-fur-2024.docx`) while extracting its own media, but which belong to KEJ's separate Hopp-slægten research instead — their original embedded filenames point directly at his own "Hopp-slægter" working folders, not the Boe material. Moved here rather than filed under the Boe-slægten deep well's own media folder, to keep that folder about the Boe-slægten source only.

**Not a deep well in its own right — deliberately.** `library/reference-index.md` has no entry for Hopp-slægten yet, and this folder isn't meant to create one prematurely. The actual Hopp-slægten manuscript(s) haven't been received: `projects/archive-digitization/context/intake-manifest.md` §3 already tracks 8 named chapters, all "Not yet received." A `reference-index.md` deep-well entry represents mining of a real, held source — right now the only Hopp-slægten material actually in this repo's hands is these two stray images and the external secondary-source page already preserved in `projects/archive-digitization/context/external-source-hopp-herredsfoged.md`. When the real manuscript(s) arrive, this folder's images should move into that new deep well's own media subfolder, and this file can be retired.
