## What Is Stored Here

**As of 2026-08-09, the source file below no longer physically lives in this folder** — moved to `restricted/deep-wells/`, per `restricted/remediation-plan-2026-08-09.md`. It was never given its own media pass, so it moved on the same default-until-assessed basis as the other source manuscripts, not because a specific problem was confirmed in this one.

- **`restricted/deep-wells/forskellige-boe-slaegter-2026.docx`** (748,710 bytes / 731 KB) — KEJ's own compilation covering several separate Boe lineages elsewhere in Denmark, distinct from the Mors/Fur line (`boe-slaegten-fra-mors-og-fur`). Per KEJ's own table of contents: Bomand/Boe (1500-tallet, on the name's origin), Boe på Mors (Christen Nielsen Boe 1690-1786), Boe på Ålborgegnen, Boe i Himmerland/Thy (Peder Andersen Boe), Boe i Sønderjylland og Slesvig, Fyn-slægten Boe (references "Boernes Slægtsbog," 1960), and Boe på Nyord ved Stege på Møn (plus ~6 pages on Nyord's own local history). Received attached directly to KEJ's 2026-08-08 email reply, landed in `incoming/` and triaged same day.
- Cornerstone reasoning: personal, unpublished compilation — not reacquirable except from KEJ — and, per its own table of contents, substantial enough (multiple distinct lineages) to likely need mining across more than one session, the same pattern as `boe-slaegten-fra-mors-og-fur`.
- **Fully read (2026-08-08).** No individuals-level connection to the Mors/Fur line was found — KEJ's own document confirms these are separate families sharing only the "Boe"/"Bomand" surname. One partial exception: a Himmerland/Thy hypothesis, already sketched in the original manuscript, is developed here into a named (still unconfirmed) candidate connecting individual. See `projects/archive-digitization/context/forskellige-boe-slaegter-extraction.md` for the full read-through.
